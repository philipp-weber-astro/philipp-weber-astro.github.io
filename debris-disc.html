Lagrangian Dust Module

A Lagrangian super-particle module for the FARGO3D hydrodynamics code, built to follow solid material — from micron-sized grains to metre-sized bodies — through gas drag, stellar radiation pressure, planetary resonances and a collisional cascade. Its flagship application is a debris-disc setup in which dust is produced by a stirred parent belt, sorted by radiation pressure, and sculpted by a migrating planet in the presence of a residual gas reservoir.

Scientific motivation

Why a dedicated dust module?

Debris discs are dynamically evolved, collisionally active systems in which the dust we observe is continuously replenished from a reservoir of larger parent bodies. Their resolved structure — rings, gaps, clumps, eccentric offsets and extended haloes — is set by the interplay of planetary perturbations, radiation pressure, collisional fragmentation, and, increasingly often, a residual amount of gas.

Each of these processes acts on a different grain size, so a fluid description with a single dust population cannot capture them. Following individual super-particles that carry their own grain size, stopping time and radiation-pressure coefficient makes the size dependence explicit, and lets the same machinery cover the gas-rich and gas-poor limits within one code.

Code architecture

Implementation in FARGO3D

The module is implemented at the setup level, leaving the FARGO3D core untouched, and separates initial conditions, gas evolution, particle dynamics, diagnostics and post-processing so that each component can be tested on its own.

Initial conditions
star, planet, gas disc, parent belt

Implemented

Super-particle dynamics

A semi-analytical, drag-implicit integrator in a kick–drift–kick arrangement, stable for arbitrarily small Stokes numbers, with an angular-momentum-conserving azimuthal drift and staggered cloud-in-cell interpolation of the gas fields.

Implemented

Gas–dust coupling

Size-dependent stopping times computed from the local gas state, and momentum-conserving back-reaction deposited onto the gas through the same interpolation kernel used to sample it (NGP, CIC or TSC).

Implemented

Radiation pressure

A size-dependent radiation-pressure coefficient reduces the effective stellar gravity for each grain, so that the blow-out size and the eccentric halo of small grains emerge from the dynamics rather than being imposed.

Implemented

CPU, GPU and MPI

A CUDA backend mirrors the CPU integrator, and the particle array is domain-decomposed with migration between neighbouring subdomains, so particles live on the rank that owns the gas they interact with.

In development

Collisional evolution

A representative-particle Monte-Carlo collision model with sticking, fragmentation and erosion, run on adaptive equal-count collision cells so that the sampling automatically refines where dust concentrates. The collision operator itself is verified against analytic solutions; coupling it into the production disc module is in progress.

In development

Dust production from a planetesimal belt

A stirred parent belt that injects fresh fragments at a prescribed production rate with a collisional size distribution, while grains lost to blow-out or drift are removed, so that the population can settle into a steady state.

In development

Radiative-transfer post-processing

Translation of the size-resolved particle distribution into images and visibilities for direct comparison with millimetre and scattered-light data.

Planned

Released documentation

A public description of the module, reproducible test configurations and archived benchmark data, to accompany the first science application.

Flagship application

The debris-disc setup

The debris-disc configuration assembles the individual components into a single, self-consistent system: a stirred belt of parent bodies feeds a collisional cascade, radiation pressure sorts the fragments by size, a planet perturbs them, and whatever gas is present damps their eccentricities. It is designed to start from an empty disc and settle into a steady state in which production, blow-out and drift balance.

Parent belt as a dust source

Fresh fragments are released on the orbits of their parent bodies at a prescribed production rate, with a collisional size distribution and a velocity dispersion set by the stirring of the belt. The number of active super-particles is a resolution knob, decoupled from the physical production rate.

Size sorting by radiation pressure

Because each grain carries its own radiation-pressure coefficient, the classic debris-disc signature emerges without being prescribed: large grains stay in a narrow ring at the belt, intermediate grains populate an extended eccentric halo, and grains below the blow-out size are promptly removed.

Collisional cascade in the gas-poor regime

In a gas-poor disc the collision speed is set by the orbital velocity dispersion rather than by differential drag. The collision model therefore uses the grains' actual peculiar velocities, which is what allows a cascade to operate at all when the grains are essentially decoupled from the gas.

Planets, resonances and residual gas

A migrating planet sweeps grains into mean-motion resonances, producing the azimuthal structure seen in resolved images. Radiation pressure limits which grain sizes stay trapped, and even a modest gas reservoir damps eccentricities and can smear the resonant clumps — the specific question the setup was built to answer.

Scientific applications

Questions enabled by the module

Planet–disc interaction

How planets sculpt rings, gaps, eccentric structures, azimuthal asymmetries and resonantly trapped grain populations, and which grain sizes retain the imprint.

Gas in debris discs

How even a modest gas reservoir alters dust transport, concentration, resonant trapping and the survival of observable structure.

Dust production and size dependence

How a dynamically evolving, collisionally active parent population connects to the smaller grains actually traced at optical, infrared and millimetre wavelengths.

Observation-facing predictions

How dynamical models translate into morphology and wavelength-dependent asymmetries that can be confronted with ALMA, JWST and scattered-light imaging.
